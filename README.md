# Voynich Decipher Lab

ヴォイニッチ手稿の「確定翻訳」ではなく、EVA文字起こし・画像メモ・ページ分類から翻訳仮説を作り、検証するNext.jsサイトです。

## ローカル起動

```bash
npm install
npm run dev
```

http://localhost:3000 を開きます。

## Vercelデプロイ

1. このフォルダをGitHubにアップロード
2. Vercelで「Add New Project」
3. GitHubリポジトリを選択
4. Framework Preset: Next.js
5. Deploy

## 注意

ヴォイニッチ手稿は未解読です。このアプリは確定翻訳ではなく、検証可能な仮説生成ツールです。
